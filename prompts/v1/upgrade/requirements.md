# ESGC UX/UI upgrade requirements

The purpose of these requirements is to help you upgrade to the new version of the ESGC to support theme switching 
between dark/light modes. Also, it will help to upgrade the contrast of the application to be WCAG AA compliant.

## Theme switching

Inspect the project:
- Add a dark and light mode support
- Review the side menu and add a theme-switching switcher button (dark/light mode).

## Theme switching

Inspect the project:
- Review application pages and provide a production-grade professional and accessible foreground/background contrast design.
- Use high contrast colors for the application's foreground and background.
